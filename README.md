# FaceMotion

Public source repository for the `com.facemotion.editor` Unity package.

The distributable package source and its documentation are in
[`Packages/com.facemotion.editor`](Packages/com.facemotion.editor/README.md).

Install FaceMotion from the public VPM repository:
`https://phinadori.github.io/PHInadori-VPM/index.json`

This repository intentionally excludes Unity development-project `Assets`, third-party
avatars, SDK copies, generated test output, and local Unity cache directories.
