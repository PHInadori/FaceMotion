# Phase H Manual Checklist

1. Open FaceMotion and confirm the integration backend defaults to `Direct`; plan and apply it as in the Phase G checklist.
2. Select `ModularAvatar` and plan without installing the package. Confirm `FM-H-MA-NOT-INSTALLED` and a Japanese unavailable reason are shown.
3. Confirm the unavailable optional path has no enabled Apply action and does not change the avatar, scene, or assets.
4. If Modular Avatar `1.18.7` is installed, select it, plan, and apply. Confirm the owned MA integration root, Merge Animator, Parameters, and Menu Installer are created, then confirm **Modular Avatar 統合を削除** detaches the hierarchy while retaining generated assets and manifest for reapply.
