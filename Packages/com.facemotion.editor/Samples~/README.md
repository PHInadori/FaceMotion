# Samples

FaceMotion 0.4.0 は importable avatar sample を同梱しません。

VRChat avatar、Yumeka、lilToon を含む第三者アセットを package に再配布しないためです。BlendShape や VRChat integration は、利用者自身が権利を持つ VRChat avatar で試してください。

最短の手順は [Getting Started](../Documentation~/Getting-Started.md) を参照してください。現時点でサンプルの提供予定や未実装の sample asset は案内しません。
